SOBRE MIM

Iniciei minha trajetória no desenvolvimento Front-End, construindo interfaces modernas, intuitivas e focadas na melhor experiência para o usuário. Atualmente, sigo evoluindo constantemente em direção ao Back-End, ampliando meus conhecimentos para desenvolver soluções completas e escaláveis.

Como parte dessa jornada, estou projetando um dos meus maiores desafios até o momento: uma plataforma de agendamento para barbearias, pensada para otimizar a gestão de horários, clientes e serviços. O objetivo é unir tecnologia, praticidade e design para entregar uma experiência eficiente tanto para os profissionais quanto para os usuários finais.

Cada etapa desse projeto representa não apenas um avanço técnico, mas também a construção do meu legado como desenvolvedor, reforçando meu compromisso com aprendizado contínuo, inovação e excelência na criação de soluções digitais.
